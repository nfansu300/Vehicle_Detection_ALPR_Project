# Vehicle Detection and ALPR Project

This repository is the scaffold for a vehicle detection and automatic license
plate recognition (ALPR) project.

## Repository layout

- `configs/` — detection, OCR, and deployment configuration
- `docs/` — architecture, datasets, model comparisons, and deployment notes
- `src/` — detection, OCR, pipeline, optimization, and utility code
- `models/` — model artifact locations and the model manifest
- `experiments/` — training and ONNX optimization work
- `results/` — evaluation and benchmark outputs
- `deployment/raspberry_pi_4/` — Raspberry Pi 4 deployment scaffold
- `tests/` — preprocessing and postprocessing tests

Implementation, model artifacts, and runtime dependencies have not yet been
added. See the placeholder files in each area before using the project.
